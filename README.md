# Lift Logger

A workout tracking app that calculate progressive overload using the Epley formula and RPE (Rate of Perceived Exertion).

## Tech Stack
- React + TypeScript (Vite)
- Express.js backend
- PostgreSQL (Neon)
- Prisma ORM

## Set up
1. Clone the repo
2. Run `npm install`
3. Add your `DATABASE_URL` to `.env`
4. Run `npm run dev:all`
